# retail-peak-hours-analysis
# Почасовой анализ продаж интернет-магазина

Проект посвящен анализу распределения выручки и количества заказов в зависимости от времени суток на основе датасета Online Retail (UCI). Цель исследования — определить пиковые часы активности клиентов и сформулировать рекомендации для бизнеса.

## Данные

- **Источник:** Online Retail (UCI)
- **Количество записей:** ~500 000
- **Период:** 01.12.2010 — 09.12.2011
- **Основные поля:** InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country

## Инструменты

- Python 3
- Pandas — обработка данных
- Matplotlib / Seaborn — визуализация

## Ход работы

1. Загрузка данных и преобразование типа `InvoiceDate` в `datetime`
2. Создание колонки `Revenue = Quantity * UnitPrice`
3. Извлечение часа из даты в колонку `Hour`
4. Группировка по часам: сумма выручки и количество заказов
5. Поиск пиковых часов
6. Визуализация с использованием двойной оси (twinx)

## Результаты

- Пик выручки: **12:00**
- Пик заказов: **12:00**
- Самый активный временной промежуток: **10:00 — 15:00**
- Наименьшая активность: **6:00** и **20:00**

## Вывод

Основная активность клиентов приходится на обеденное время. Рекомендуется усиливать маркетинговую активность в промежутке с 10:00 до 15:00 и проверить причины возвратов в 6:00.
